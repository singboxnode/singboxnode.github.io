第一章 认识你的数字钥匙串：Shadowrocket节点本质解析

1.1 什么是Shadowrocket节点？

节点在Shadowrocket中扮演着网络"中转站"的角色，每个节点都像是一把独特的钥匙，可以打开特定的网络通道。这些节点支持Shadowsocks、VMess、Trojan等多种协议，它们的不同组合构成了用户访问互联网的"密钥环"。

1.2 节点生命周期理论

一个节点的价值并非永恒不变，它会经历四个阶段：
- 蜜月期：刚添加时连接迅速稳定
- 稳定期：性能保持良好状态
- 衰退期：开始出现延迟、掉包现象
- 死亡期：完全无法连接

理解这个周期律能帮助我们更理性地做出删除决策。

第二章 删除节点的五大黄金理由

2.1 性能衰退：当快车道变成慢车道

节点速度下降30%以上时，就像高速公路上突然出现的施工路段，不仅影响当前使用体验，还可能拖累整个网络策略的效率。定期进行速度测试（推荐使用Cloudflare Speed Test）是识别这类节点的好方法。

2.2 安全警报：信任的瓦解

当出现以下情况时，应立即考虑删除节点：
- 节点提供商发生数据泄露事件
- 检测到异常流量（如未经授权的数据上传）
- 证书出现不匹配警告

2.3 地理限制：当"梯子"够不着目标

某些节点可能因政策调整无法访问你需要的资源，就像一把无法开启新锁的旧钥匙，保留它们只会造成列表混乱。

2.4 成本优化：精简付费节点

对于付费订阅用户，删除那些使用率低于10%的节点，每年可能节省数百元订阅费用。

2.5 美学需求：极简主义网络管理

超过20个节点的列表会显著降低操作效率，保持7-10个优质节点是最佳实践。

FAQ

PassWall2 如何自动切换最优节点？
PassWall2 会定期测试节点延迟和丢包率，并结合策略组自动切换到最优节点。无需手动干预即可保证网页、视频和游戏流量高速稳定访问，优化整体网络体验。
V2RayA 在 Linux 系统中如何开机自启？
可通过 systemd 创建启动项或在启动脚本中添加 V2RayA 启动命令。编辑 /etc/systemd/system/v2raya.service 文件并设置 `Restart=always`，执行 `systemctl enable v2raya` 使其随系统自动启动。
何为 fake-ip 模式，它的优缺点是什么？
fake-ip 是通过伪造 DNS 返回的 IP 地址让客户端透明代理流量，优点是兼容性好、无需修改应用代理设置；缺点是可能导致某些证书校验或 SNI 伪装失效，需要配合 DNS 与证书策略谨慎使用。
Clash 如何通过策略组实现多节点负载均衡？
Clash 支持策略组功能，可以根据节点延迟、地区或用途自动选择最佳节点处理流量，实现多节点负载均衡。有效提高访问速度和稳定性，保证网页浏览、视频播放和游戏流畅。
Mellow 的 TUN 模式与 SOCKS5 代理区别是什么？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理通常只影响特定应用。TUN 更适合全局加速、游戏和视频应用，保证所有流量走节点，提高网络稳定性和速度。
Potatso Lite 节点手动切换有什么优势？
手动切换节点可以让用户根据网络延迟和用途选择最合适的节点，适合在节点不稳定或特殊访问需求下使用。虽然不自动，但可以灵活调整，提高访问效率。
Netch 使用 TAP 驱动时 Windows 弹出网络变更提示，该如何处理？
这是正常现象，TAP 虚拟网卡会改变系统网络状态。建议在首次启用时允许驱动安装并授予网络权限，若频繁弹窗可在网络设置中调整网络识别类型或将 TAP 设为非计量连接。
Sing-box 可以替换 Clash 的 YAML 配置吗？
可以。Sing-box 原生支持解析 Clash YAML 配置，并自动转换为自身 JSON 结构。节点和规则基本兼容，但部分脚本和自定义插件可能需要手动调整。
Matsuri 可以用于 Android 吗？
Matsuri 主要针对桌面平台开发，目前并未推出 Android 版本。但可使用其配置文件在兼容的客户端（如 Nekobox 或 Clash Android）中加载以获得类似体验。
Mellow TUN 模式与 SOCKS5 的差别？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理只影响支持代理的应用。TUN 适合全局加速，如游戏、视频和浏览器流量，提高网络稳定性和覆盖范围。
